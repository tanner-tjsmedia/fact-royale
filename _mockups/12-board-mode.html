Why this is here. It is a concept, not something scheduled. The point is to check that a second game can be built without inventing a second visual language: the shield, the five category colours, the gold, the type scale and the card chrome are all unchanged from the daily quiz. The only new component on this page is the value tile. If a new mode needs more than one new component, the system is too thin — and on this evidence it is not.
